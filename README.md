# ScienceWord Overlay Pro Universal (C# WPF - 3 Tầng Tương Tác)

Ứng dụng vẽ hình học, tô màu và chú thích trực tiếp trong **lớp trong suốt toàn màn hình**, tương tác mượt mà với **Word, PowerPoint, Excel, Paint, PDF Editor, Trình duyệt Web, Scribble...**

## 3 Tầng Tương Tác Toàn Diện
1. **Tầng 1 — Microsoft Office COM (Word, PowerPoint, Excel):**
   - Chọn hình trong Word / PowerPoint / Excel -> bấm **`Đọc Office`** -> bấm **`Tô hình Office`** hoặc vẽ thêm -> bấm **`Chèn vào App`** để chèn khớp tọa độ.
2. **Tầng 2 — Đũa thần Flood-Fill (`Đũa thần`) cho PDF, Web, Paint, Scribble:**
   - Chọn **`Đũa thần`**, chọn màu & kiểu tô (`Tô đặc`, `Gạch chéo`, `Ca rô`, `Chấm bi`), click 1 phát vào bên trong bất kỳ hình kín nào đang hiện trên màn hình -> tự động dò viền và tô màu trong suốt khớp 100%.
3. **Tầng 3 — Tự động dán (`Chèn vào App`) cho mọi phần mềm khác:**
   - Thanh công cụ tự nhận diện tên app đang mở phía sau (`Đích: Paint / Chrome / PDF...`). Bấm **`Chèn vào App`** sẽ tự copy ảnh PNG trong suốt, chuyển về app đích và gửi `Ctrl+V`.
